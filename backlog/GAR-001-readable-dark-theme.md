# GAR-001: Readable VS Code–inspired dark theme

- Status: idea; deferred to a separate task.
- Priority: unassigned.
- Source: user request in this chat, 2026-10-09; migrated from BACKLOG.md.
- Dependencies: none identified.

## Problem

Some existing text is not readable.

## Desired outcome

A dark, VS Code–like theme with consistently readable, high-contrast text
across the dashboard, sidebar, forms, alerts, metrics, charts, and interactive states.

## Proposed acceptance criteria

- Measure text/background contrast, including muted labels and chart text.
- Target at least 4.5:1 for normal text and 3:1 for large text.
- Check desktop and mobile layouts.

## Scope note

No styling implementation was included in the browser-session test work.
